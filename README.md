# Производственный календарь России

- [Подписаться на календарь](webcal://alexandrdev.github.io/production-calendar-ru/calendar.ics)
- [Скачать ICS](https://alexandrdev.github.io/production-calendar-ru/calendar.ics)

## Обновление календаря

1. Исправьте нужный файл `data/ГОД.json` или создайте файл нового года по образцу `data/2027.json`. Источники: КонсультантПлюс — [2026](https://www.consultant.ru/law/ref/calendar/proizvodstvennye/2026/), [2027](https://www.consultant.ru/law/ref/calendar/proizvodstvennye/2027/). Праздники берите из раздела «Нерабочие праздничные дни», перенесённые выходные — из раздела «Перенос выходных дней», сокращённые рабочие дни — из комментария к календарю. Учитывайте также перенос на следующий рабочий день при совпадении праздника с выходным (кроме 1–8 января).
2. Укажите год, ссылку на источник и события. `start` и `end` — даты включительно в формате `YYYY-MM-DD`; `kind` — `holiday`, `short` или `transfer`. Сохраняйте ключи `key` по образцу существующих данных.
3. Для 1–6 и 8 января используйте `key: "new-year"` и название «Новогодние каникулы», для 7 января — `key: "christmas"` и название «Рождество Христово». Перенесённые выходные добавляйте отдельными событиями с `kind: "transfer"`, `key: "transfer"` и исходной датой в `description`. Обычные субботы и воскресенья не добавляйте.
4. Пересоберите календарь (Python 3.9+, без сторонних библиотек):

   ```sh
   python3 generate.py
   ```

5. Закоммитьте и отправьте изменённые JSON и `calendar.ics` в ветку `main`. После публикации GitHub Pages подписка получит изменения при следующем обновлении.

Старые JSON сохраняйте: итоговый календарь содержит все добавленные годы. Не меняйте имя `calendar.ics` и адрес размещения, чтобы подписка продолжала обновляться.
